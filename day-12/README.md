# Day 12: Analytics Dashboard

This project is an interactive, responsive analytics dashboard built with **React**, **Vite**, **Tailwind CSS**, and **Recharts**.

## Features

- **Grid-based Dashboard**: A 3x3 responsive grid layout that supports dynamic reordering via drag-and-drop.
- **Auto-flow Dense**: The layout automatically refills gaps in the grid whenever a card is moved or resized.
- **Customizable Layout**: Each chart card can be toggled between standard (1 column) and wide (2 column) widths.
- **Add New Charts**: An interactive modal allows users to configure new metric cards with custom titles, categories, and chart types.
- **Theme Support**: Integrated light and dark mode toggles with real-time UI adaptation.
- **Live Visualizations**: Recharts integration provides interactive, demo-based data visualizations for various metrics.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Navigate to the `day-12` folder:
   ```bash
   cd day-12
   ```
2. Install the required dependencies:
   ```bash
   npm install
   ```

### Running the Project
To start the development server:
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.
