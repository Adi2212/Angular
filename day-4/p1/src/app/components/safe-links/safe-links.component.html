Custom Directive: a[appSafeLink]

Enhancing anchor tags to intercept clicks, verify navigation, and inject telemetry parameters.

Safe External Navigation Directive

Restricts and wraps <a> tags. When clicked, it displays a confirmation prompt, sets target="_blank", rel="noopener noreferrer", and automatically appends ?from=... query parameter.

Directive Mechanics Explained:

  • Selector Restriction: a[appSafeLink] only attaches to <a> anchor tags.
  • Host Listener: Uses host: { '(click)': 'onConfirmLeavePage($event)' } to intercept user clicks before the browser navigates.
  • ElementRef Injection: Dynamically enhances DOM element with security headers (rel="noopener") and appends ?from={{ customAppName }} to the URL.
