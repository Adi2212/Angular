Built-in Angular Pipes

Transforming text, dates, currencies, numbers, arrays, and objects in template expressions.

1. Text Transformation Pipes

UpperCase · LowerCase · TitleCase

Transforms string capitalization dynamically without mutating source models.

Original: {{ textInput }}
{{ '{' }}{{ '{' }} text | uppercase {{ '}' }}{{ '}' }}: {{ textInput | uppercase }}
{{ '{' }}{{ '{' }} text | lowercase {{ '}' }}{{ '}' }}: {{ textInput | lowercase }}
{{ '{' }}{{ '{' }} text | titlecase {{ '}' }}{{ '}' }}: {{ textInput | titlecase }}

2. DatePipe Formatting

DatePipe

Formats dates and timestamps into localized date strings.

Raw Value: {{ selectedDate }}
Selected Format: {{ parsedDate | date:dateFormat }}
date:'fullDate': {{ parsedDate | date:'fullDate' }}
date:'MMMM d, yyyy': {{ parsedDate | date:'MMMM d, yyyy' }}

3. Financial & Numerical Pipes

CurrencyPipe · DecimalPipe · PercentPipe
@for (item of products; track item.id) { }
Product (TitleCase) Original Price (Decimal) Discount (Percent) Final Price (Currency) Release Date (DatePipe) Stock Status
{{ item.name | titlecase }} {{ item.price | number:numberFormat }} {{ item.discountRate | percent:'1.0-1' }} OFF {{ (item.price * (1 - item.discountRate)) | currency:selectedCurrency:currencyDisplay:'1.2-2' }} {{ item.releaseDate | date:'mediumDate' }} {{ item.inStock ? 'In Stock' : 'Out of Stock' }}

4. SlicePipe Array Slicing

SlicePipe

Creates a subset of a list or string directly in template: items | slice:start:end

@for (item of products | slice:sliceStart:sliceEnd; track item.id; let i = $index) {
#{{ sliceStart + i + 1 }} {{ item.name | titlecase }} {{ item.price | currency:'USD' }}
}

5. KeyValuePipe & JsonPipe

KeyValuePipe · JsonPipe

Iterates over JavaScript objects & formats JSON for visual inspection.

@for (entry of serverConfig | keyvalue; track entry.key) {
{{ entry.key }}: {{ entry.value }}
}
Debug Output ({{ '{' }}{{ '{' }} serverConfig | json {{ '}' }}{{ '}' }}): 
{{ serverConfig | json }}
