Custom Pipes Playground

Building reusable transformation pipelines: Temperature, File Size, Time Ago, and Filter.

1. Temperature Converter Pipe

| temperature:'C':'F'

Calculates conversion formulas & attaches localized unit symbols.

Input Temp: {{ currentCelsius }} °C Precision: {{ tempPrecision }}
Input (Celsius) {{ currentCelsius | temperature:'C':'C':tempPrecision }}
➔
Output (Fahrenheit) {{ currentCelsius | temperature:'C':'F':tempPrecision }}

2. File Size Formatter Pipe

| fileSize:precision

Converts raw byte integers into human-readable data units (B, KB, MB, GB).

Raw Bytes: {{ rawBytes | number }} Decimal Places: {{ filePrecision }}
{{ rawBytes | fileSize:filePrecision }}
